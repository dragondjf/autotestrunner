## 一、三套方案总览

| 维度 | 方案一「极简高效」 | 方案二「深色科技」 | 方案三「明亮协作」 |
|------|------------------|------------------|------------------|
| 一句话定位 | 现代 SaaS 工作台，效率至上 | 数据运维监控台，科技硬核 | 协作式项目管理台，亲和友好 |
| 参考质感 | Linear / Notion / Vercel Light | Vercel Dark / Grafana / 终端 | Trello / Asana / 多彩 Bento |
| 视觉基调 | 浅色 · 留白 · 克制 | 深色 · 高对比 · 数据化 | 暖色 · 圆润 · 活泼 |

| 布局侧重 | 列表 + 统计卡 | 看板 + 实时监控 | 卡片网格 + Bento |
| 目标用户 | 高频使用的测试工程师 | 偏向研发/自动化运维的工程师 | 多角色协作团队 |

| 推荐指数 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

## 二、方案一「极简高效 Minimalist Light」

### 设计图

- [方案一·任务工作台（设计图）](file:///F:/workspace/yfjzworkspace/webspace/aispace/autotestrunner/docs/需求与原型设计/ux-prototypes/方案一_极简高效_任务工作台.png)
- [方案一·任务执行监控（设计图）](file:///F:/workspace/yfjzworkspace/webspace/aispace/autotestrunner/docs/需求与原型设计/ux-prototypes/方案一_极简高效_执行监控.png)

### 设计理念

以「任务为中心」的效率型工作台。信息层级分明、操作路径最短、视觉噪音最少，让高频使用的测试工程师 3 秒内定位状态、1 步发起操作。适合作为**默认主方案**。

### 设计规范

| 项目 | 规范 |
|------|------|
| 背景 / 卡片 | `#F7F8FA` / `#FFFFFF` |
| 侧边栏 | 深色 `#1B1F2A`，激活项靛蓝胶囊 |
| 主色 | 靛蓝 `#3B5BDB`（按钮/选中/进度） |
| 状态色 | 成功 `#00A870` / 失败 `#E34D59` / 执行中 `#3B5BDB`(脉冲点) / 待执行 `#ED7B2F` |
| 排版 | 现代无衬线（Outfit / Plus Jakarta Sans），大标题 + 细字距，正文行宽 65-75ch |
| 阴影 | 柔和中性阴影，1px 细边框，圆角 8px |
| 布局 | 左侧窄导航 + 顶部工具栏 + 内容区；统计卡行 + 表格 |

### 覆盖页面（设计图 2 张 + 延伸）

| 页面 | 状态 |
|------|------|
| 任务工作台（统计卡 + 列表） | ✅ 已出图 |
| 任务执行监控（日志 + 进度 + 截图） | ✅ 已出图 |
| 录制项目 / 测试计划 / 测试报告 | 同风格延伸（表格 + 筛选 + 分页） |
| 创建任务分步向导 | 右侧滑出面板，4 步流程 |

### 交互要点

- 核心操作不超过 3 步：新建 → 配置 → 执行。
- 状态实时刷新（运行中任务自动轮询），进度条 + 状态标签。
- 列表支持筛选、分页、批量勾选执行。
- 执行监控：日志自动滚动、截图点击放大、可停止执行。

## 三、方案二「深色科技 Dark Operations」

### 设计图

- [方案二·任务看板（设计图）](file:///F:/workspace/yfjzworkspace/webspace/aispace/autotestrunner/docs/需求与原型设计/ux-prototypes/方案二_深色科技_任务看板.png)
- [方案二·AI 录制执行（设计图）](file:///F:/workspace/yfjzworkspace/webspace/aispace/autotestrunner/docs/需求与原型设计/ux-prototypes/方案二_深色科技_AI录制执行.png)

### 设计理念

面向自动化运维与研发的「控制台」体验。深色高对比、数据密集、实时状态可视化，AI 录制过程以"Agent 正在行动"的科技感呈现。适合**突出 AI 能力、偏向研发/DevOps 场景**。

### 设计规范

| 项目 | 规范 |
|------|------|
| 背景 | 近黑 `#0A0A0C` + 细网格纹理；面板 `#121216` |
| 边框 | `#1F2937` 细分隔线 |
| 主色 | 青色 `#22D3EE`（高亮/进度/执行中） |
| 状态色 | 待执行 琥珀 `#F59E0B` / 执行中 青 `#22D3EE` / 已完成 绿 `#10B981` / 失败 红 `#EF4444` |
| 排版 | 无衬线 + 等宽数字（monospace）时间戳与指标 |
| 布局 | 看板 4 列 / 分屏（时间线 + 浏览器视口） |

### 覆盖页面（设计图 2 张 + 延伸）

| 页面 | 状态 |
|------|------|
| 任务看板（待执行/执行中/已完成/失败 4 列） | ✅ 已出图 |
| AI 录制执行（步骤时间线 + LLM 状态 + 浏览器预览） | ✅ 已出图 |
| 浏览器录制监控 | 同风格延伸（录制中监控面板） |
| 报告详情 | 数据大屏感（指标 + 趋势） |

### 交互要点

- 看板卡片跨列拖拽更新状态，执行中卡片显示进度环。
- AI 录制：步骤时间线实时推进，"LLM 正在规划"动效，失败步骤红色 + 截图展开。
- 执行监控可全屏沉浸，日志流终端风格。
- 状态颜色语义全局统一，深色下对比度 ≥ 4.5:1。

## 四、方案三「明亮协作 Vivid Collaborative」

### 设计图

- [方案三·录制项目看板（设计图）](file:///F:/workspace/yfjzworkspace/webspace/aispace/autotestrunner/docs/需求与原型设计/ux-prototypes/方案三_明亮协作_项目看板.png)
- [方案三·报告详情（设计图）](file:///F:/workspace/yfjzworkspace/webspace/aispace/autotestrunner/docs/需求与原型设计/ux-prototypes/方案三_明亮协作_报告详情.png)

### 设计理念

面向多角色协作的"友好工作台"。暖色底、彩色卡片、圆润亲和，用色彩区分业务模块，降低新手门槛。适合**希望 AI 录制被开发/产品广泛使用、强调团队协作**的场景。

### 设计规范

| 项目 | 规范 |
|------|------|
| 背景 | 暖白 `#FAF9F6` + 轻柔色晕 |
| 主色 | 珊瑚 `#FF6B6B`（主按钮/激活） |
| 模块色 | 蓝/绿/琥珀/紫/粉 多色卡片区分业务 |
| 圆角 | 16px 大圆角，柔和同色系阴影 |
| 排版 | 圆润现代无衬线，间距宽松 |
| 布局 | Bento 卡片网格 + 悬浮引导卡 |

### 覆盖页面（设计图 2 张 + 延伸）

| 页面 | 状态 |
|------|------|
| 录制项目管理（彩色卡片网格 + 双录制入口） | ✅ 已出图 |
| 报告详情（指标卡 + 趋势图 + 视频 + 步骤表） | ✅ 已出图 |
| 测试任务 / 测试计划 | 同风格延伸（看板/列表可切换） |
| 空态引导 | 插画 + 双入口引导卡 |

### 交互要点

- 项目卡片 hover 显示操作（查看/编辑/删除），彩色状态胶囊。
- 悬浮引导卡提供「开始 AI 录制 / 开始浏览器录制」双入口。
- 报告详情：彩色指标卡 + 平滑趋势图 + 视频播放 + 步骤表（含截图）。
- 批量操作、筛选、拖拽排序在彩色体系下保持一致。
